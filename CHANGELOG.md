# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.0.7] - 2024-11-29

### Added
- Professional GitHub Actions CI/CD pipeline
- Automated release workflow with cross-platform binaries
- CHANGELOG.md for version tracking
- Makefile for easy build/install commands

### Changed
- Version scheme aligned with git tags

## [0.0.6] - 2024-11-28

### Added
- Full TUI web browsing with keyboard navigation
- AI chat panel with tool-calling support (navigate, scroll, follow links)
- Multi-engine search (DuckDuckGo, Wikipedia, arXiv, PubMed, Google Scholar, OpenLibrary)
- JavaScript rendering via headless Chrome
- Bookmarks and history with SQLite storage
- Cosmic dark theme
- Tab support
- RAG integration (optional)

### Features
- OpenAI-compatible AI providers (OpenRouter, OpenAI, Ollama, custom)
- Search prefixes for different engines (w:, a:, s:, d:, g:, p:, ol:)
- Full keyboard navigation with vim-style bindings

## [0.0.5] - 2024-11-27

### Added
- Initial Rust implementation
- Basic browser functionality
- URL navigation
- Content rendering
