# 🌊 Azul: A Terminal Web Browser

Azul is a powerful and minimalist web browser designed to run entirely within your terminal emulator. It offers a fast, keyboard-driven experience for browsing the world in the comfort of your command line.

## ✨ Features

* **Terminal-Native Interface:** Experience web content without leaving your command line environment.

* **Minimalist Design:** Focuses on content by stripping away unnecessary graphical elements.

* **Fast & Efficient:** Leveraging the speed and memory safety of Rust.

* **Keyboard-Driven Navigation:** Designed for efficient use with minimal mouse interaction.

* **Pure Text Rendering:** Renders web pages into a readable text format.
